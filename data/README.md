# Data Directory

## Dataset: HTRU2 — Pulsar Candidate Classification

The raw dataset is NOT committed to this repository due to size.

## How to Download

### Option 1 — Direct Download
1. Go to: https://archive.ics.uci.edu/dataset/372/htru2
2. Click **Download**
3. Extract the ZIP file
4. Copy `HTRU_2.csv` into this `data/` folder

### Option 2 — Command Line
```bash
wget https://archive.ics.uci.edu/ml/machine-learning-databases/00372/HTRU2.zip
unzip HTRU2.zip
```
